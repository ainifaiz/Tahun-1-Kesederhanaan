# Ringkasan pengujian

Ujian automatik dijalankan dalam Chromium tanpa antara muka, menggunakan Playwright. Tiada alat ujian diperlukan untuk memainkan projek ini.

## Lulus

- Latihan awal pensel dan peralihan ke Misi 1.
- Keseluruhan Misi 1: tiga pilihan, jawapan belum tepat, petunjuk dan perkongsian rumah.
- Keseluruhan Misi 2: enam langkah tindakan/kepentingan untuk makanan, air dan kertas.
- Keseluruhan Misi 3: empat pasangan, pertanyaan berselang, kedua-dua label selepas jawapan tepat dan perkongsian perbezaan.
- Keempat-empat perasaan dalam Misi 4 diterima; pilihan boleh diubah dan sebab dikongsi secara lisan.
- Misi 5: Belum lagi tidak memberi bintang; Ya, sudah memberi satu bintang; klik siap tidak boleh menggandakan bintang.
- Pengesahan pilihan ibu bapa kekal selepas muat semula.
- Kemajuan dan bintang kekal selepas muat semula; Sambung kembali ke misi terakhir.
- Penamat hanya muncul selepas empat misi pembelajaran serta tiga amalan rumah selesai.
- Main Semula mengulang pembelajaran dan mengekalkan bintang.
- Padam Kemajuan meminta pengesahan; Batal tidak memadam data.
- Kedudukan jawapan tepat boleh muncul di kiri atau kanan.
- Mod penyimpanan disekat: permainan terus berfungsi dan memaparkan mesej simpanan tidak tersedia.
- Simulasi Web Speech API: tiada bacaan automatik semasa halaman dibuka, bahasa ms-MY digunakan, butang Dengar memanggil bacaan, tetapan bunyi mati menghalang bacaan.
- Pelayar tanpa suara Melayu memaparkan mesej yang sepadan dan permainan masih berfungsi.
- Tetapan kurangkan animasi; dialog panduan boleh ditutup dengan Escape.
- Susun atur diuji pada saiz komputer 1280×900, telefon 390×844 dan iPad 768×1024. Tangkapan skrin pembukaan, pilihan dan bintang disemak. Paparan perbandingan telefon diperbetulkan untuk mengelakkan limpahan mendatar.
- Semakan sintaks JavaScript dan pemuatan aset SVG tempatan.

## Batasan ujian

Saiz telefon/iPad disimulasikan dalam Chromium; ujian ini bukan ujian pada iPhone atau iPad fizikal dan tidak mengesahkan semua versi Safari. Bunyi suara Melayu sebenar tidak dapat didengar dalam persekitaran ujian; panggilan API diuji dengan simulasi. Cuba butang Dengar pada peranti PdPR sebenar sebelum digunakan. Permainan tidak mengesahkan perlakuan sebenar murid atau menilai perkongsian lisan.

Projek belum diterbitkan ke GitHub Pages. Ujian pemuatan setempat tidak membuktikan tetapan penerbitan repositori pengguna; ikuti README untuk menerbitkannya.
